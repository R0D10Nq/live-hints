# Live Hints v1.0.3

Обновление Windows-аудиоконтура с актуальной версией `pyaudiowpatch` и дополнительной проверкой совместимости WASAPI.

## Обновлено

- `pyaudiowpatch` обновлён с `0.2.12.7` до `0.2.12.8`;
- версия приложения поднята до `1.0.3`;
- подготовлены новые установщик, portable-сборка и файл контрольных сумм.

Выпуск `pyaudiowpatch 0.2.12.8` содержит готовый wheel для CPython 3.11 x64 на Windows. Используемые Live Hints интерфейсы сохранили совместимость: `PyAudio`, `get_default_wasapi_loopback`, `get_device_info_by_index`, `isLoopbackDevice`, `paFloat32`, `paInt16`, callback-потоки и `Stream.read(..., exception_on_overflow=False)`.

## Проверено

Перед упаковкой выпуск проверен 622 автоматическими проверками: 304 JavaScript, 288 Python и 30 E2E. `npm audit` не обнаружил уязвимостей высокой важности, ESLint завершился без ошибок.

Помимо автоматических проверок выполнены проверки Windows-аудиоконтура на реальном оборудовании:

- обнаружены доступные устройства и WASAPI loopback-устройства;
- открыт loopback-поток и успешно прочитан аудиобуфер;
- открыт и корректно закрыт микрофонный поток;
- подтверждена штатная работа запуска, остановки и закрытия потоков.

Эти проверки подтверждают совместимость протестированной конфигурации, но не гарантируют одинаковое поведение всех аудиодрайверов и устройств.

## Обновление с v1.0.2

Для установленной версии используйте новый установщик. Для portable-варианта замените исполняемый файл и сохраните свои локальные настройки.

Установщик и portable-сборка не управляют Python-окружением. Чтобы обновить зависимости в отдельном окружении Live Hints, выполните в каталоге проекта:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install --upgrade -r python\requirements.txt
```

Если окружение уже существует, достаточно выполнить последние две команды. При использовании другого окружения запускайте их его интерпретатором. После обновления проверьте:

```powershell
.\venv\Scripts\python.exe -m pip show pyaudiowpatch
```

Ожидаемая версия — `0.2.12.8`.

## Файлы

- `Live.Hints.Setup.1.0.3.exe` — установщик;
- `LiveHints-Portable-1.0.3.exe` — portable-сборка;
- `SHA256SUMS.txt` — контрольные суммы.

Исполняемые файлы не подписаны коммерческим сертификатом. Windows может показать предупреждение SmartScreen; перед запуском сверьте SHA-256 с опубликованным файлом контрольных сумм.

## Требования

- Windows 10 или Windows 11;
- Python 3.11 или новее и зависимости из `python/requirements.txt`;
- совместимая NVIDIA GPU с CUDA для текущего STT-пути;
- Ollama и загруженная текстовая модель, по умолчанию `qwen3:8b`.

Portable-сборка не включает системный Python, CUDA, Ollama и модели. Она не является полностью автономной.

## Известные ограничения

- рабочий LLM-путь — только локальный Ollama;
- STT работает в режиме `cuda`, ориентирован на русский язык и не имеет автоматического перехода на CPU;
- совместимость конкретной NVIDIA GPU зависит от установленной сборки PyTorch и поддерживаемой ею архитектуры CUDA;
- автоматический выбор loopback-устройства может не совпасть с текущим устройством вывода Windows;
- микрофонный путь использует фиксированный формат `16 кГц / моно`, а loopback-путь рассчитан на стереосигнал;
- пользовательские инструкции и облачные провайдеры остаются в планах;
- время ответа LLM зависит от выбранной модели и оборудования.
