# Live Hints v1.0.0

Первый публичный выпуск Live Hints с установщиком и portable-сборкой для Windows.

## В выпуске

- захват системного звука через WASAPI loopback;
- локальная транскрипция русской речи через `faster-whisper`;
- потоковые подсказки через Ollama;
- окно поверх остальных приложений;
- история сессий;
- два аудиоканала при включённой настройке;
- анализ скриншота через Ollama Vision при установленной модели LLaVA;
- 304 JavaScript-теста, 281 Python-тест и 30 E2E-сценариев в локальном прогоне.

## Файлы

- `Live.Hints.Setup.1.0.0.exe` — установщик;
- `LiveHints-Portable-1.0.0.exe` — portable-сборка;
- `SHA256SUMS.txt` — контрольные суммы.

## Требования

- Windows 10 или Windows 11;
- Python 3.10 или новее и зависимости из `python/requirements.txt`;
- совместимая NVIDIA GPU с CUDA для текущего STT-пути;
- Ollama и загруженная текстовая модель, по умолчанию `qwen3:8b`.

Portable-сборка не включает системный Python, CUDA, Ollama и модели. Она не является полностью автономной.

Файлы выпуска не подписаны коммерческим сертификатом разработчика. Windows SmartScreen может показать предупреждение; перед запуском сверьте SHA-256.

## Известные ограничения

- рабочий LLM-путь в этом выпуске — только локальный Ollama;
- STT работает в режиме `cuda` и ориентирован на русский язык;
- время ответа LLM зависит от модели и оборудования, ориентиры проекта: первый токен 2–3 секунды, полный ответ 18–25 секунд;
- пользовательские инструкции и облачные провайдеры остаются в планах.
