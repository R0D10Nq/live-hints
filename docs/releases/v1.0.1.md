# Live Hints v1.0.1

Исправление зависимостей безопасности для первого публичного выпуска.

## Исправлено

- удалён обязательный `chromadb`, для которого нет исправленного выпуска после CVE-2026-45829;
- инициализация ChromaDB принудительно отключена даже в старом виртуальном окружении, где пакет уже установлен;
- Advanced RAG использует существующий резервный поиск по векторным представлениям в памяти;
- мгновенная персистентная база готовых ответов временно отключена;
- `requests` обновлён до `2.34.2`, содержащего исправление CVE-2026-25645;
- добавлены регрессионные тесты состава зависимостей и безопасного резервного режима во время работы.

## Обновление с v1.0.0

Установщик и portable-сборка не управляют Python-окружением. Обычная установка нового `python/requirements.txt` обновит `requests`, но не удалит ранее установленный ChromaDB. Для выделенного окружения проекта выполните:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip uninstall -y chromadb
.\venv\Scripts\python.exe -m pip install --upgrade -r python\requirements.txt
```

Если проект использует другое виртуальное окружение, выполните те же команды его интерпретатором. Не удаляйте ChromaDB из общего системного Python, если он нужен другим приложениям; создайте для Live Hints отдельное окружение.

## Файлы

- `Live.Hints.Setup.1.0.1.exe` — установщик;
- `LiveHints-Portable-1.0.1.exe` — portable-сборка;
- `SHA256SUMS.txt` — контрольные суммы.

## Требования

- Windows 10 или Windows 11;
- Python 3.11 или новее и зависимости из `python/requirements.txt`;
- совместимая NVIDIA GPU с CUDA для текущего STT-пути;
- Ollama и загруженная текстовая модель, по умолчанию `qwen3:8b`.

Portable-сборка не включает системный Python, CUDA, Ollama и модели. Она не является полностью автономной.

Файлы выпуска не подписаны коммерческим сертификатом разработчика. Windows SmartScreen может показать предупреждение; перед запуском сверьте SHA-256.

## Известные ограничения

- рабочий LLM-путь — только локальный Ollama;
- STT работает в режиме `cuda` и ориентирован на русский язык;
- постоянное хранилище ChromaDB отключено до появления исправленного выпуска;
- время ответа LLM зависит от модели и оборудования;
- пользовательские инструкции и облачные провайдеры остаются в планах.
