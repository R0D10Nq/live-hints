# Live Hints v1.5.6

Крупное кумулятивное обновление интерфейса, генерации подсказок, изоляции тестового профиля и строгих проверок качества.

## Обновлено

- **Изоляция тестового профиля и синтетического аудио (`main.js`, `main/process-manager.js`, `main/ipc-handlers.js`):** В режиме тестирования (`NODE_ENV=test` или `LIVE_HINTS_USER_DATA_DIR`) хранилище настроек `electron-store` и `userData` изолируются во временной директории ОС; при `LIVE_HINTS_SYNTHETIC_AUDIO=1` исключается запуск физических WASAPI-процессов захвата звука.
- **Перетаскивание окна и скролл настроек (`renderer/styles/layout.css`, `renderer/styles/app.css`):** Исправлена область перетаскивания заголовка окна и добавлена независимая вертикальная прокрутка панели настроек при сохранении фиксированной шапки вкладок.
- **Выбор модели Ollama и защита от спама подсказок (`renderer/app.js`, `renderer/modules/app/app-models.js`):** Добавлен селектор модели Ollama в настройках, внедрён дебаунс авто-подсказок (800–1800 мс) с фильтрацией коротких реплик и блокировкой параллельных запросов.
- **Качество подсказок и классификация вопросов (`python/classification.py`, `python/prompts.py`):** Устранены шаблонные подзаголовки и подмешивание личного резюме в чисто технические вопросы, обновлён классификатор вопросов.
- **Полный набор элементов управления HUD (`renderer/`):** Добавлены кнопка приглушения микрофона (`Mute`), индикатор уровня звука (`VU-метр`), выбор аудиоустройств, масштабирование кегля подсказок (`A-` / `A+`), режим сквозного клика (`Click-Through`), перенос на второй монитор и экспорт сессии в Markdown.
- **Приоритет локального кэша Whisper и обход системного прокси для Ollama (`python/stt/transcriber.py`, `python/llm/provider.py`):** Ускорен локальный старт STT без лишних сетевых обращений и исключён перехват трафика к `127.0.0.1:11434` системным прокси Windows.

## Обновление с предыдущих версий

Для установленной версии используйте новый установщик `Live.Hints.Setup.1.5.6.exe`. Для portable-варианта замените исполняемый файл `LiveHints-Portable-1.5.6.exe` и сохраните свои локальные настройки.

Установщик и portable-сборка не управляют Python-окружением. Чтобы обновить зависимости в отдельном окружении Live Hints, выполните в каталоге проекта:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install --upgrade -r python\requirements.txt
```

## Требования

- Windows 10 или Windows 11;
- Python 3.11 или новее и зависимости из `python/requirements.txt`;
- совместимая NVIDIA GPU с CUDA для локального STT-пути;
- Ollama и загруженная текстовая модель, по умолчанию `qwen3:8b`.
