# Live Hints v1.0.2

Оперативное обновление зависимостей безопасности после выпуска 1.0.1.

## Исправлено

- `aiohttp` обновлён с `3.13.2` до `3.14.3`, включая исправления опубликованных уязвимостей;
- версия приложения поднята до `1.0.2`;
- подготовлены новые установщик, portable-сборка и файл контрольных сумм.

Перед упаковкой выпуск проверен 621 тестом: 304 JavaScript, 287 Python и 30 E2E.

Обновление `aiohttp` закрывает текущий набор из 32 уведомлений Dependabot для этого пакета, включая исправления высокой важности в обработке сжатых ответов и HTTP-парсере. Это не является гарантией отсутствия будущих уязвимостей: после установки следите за новыми уведомлениями GitHub и обновляйте зависимости контролируемо.

## Обновление с v1.0.0 и v1.0.1

Установщик и portable-сборка не управляют Python-окружением. Простая замена файла приложения не удалит старый `chromadb` и не обновит уже созданное окружение. Для отдельного окружения Live Hints выполните в каталоге проекта:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip uninstall -y chromadb
.\venv\Scripts\python.exe -m pip install --upgrade -r python\requirements.txt
```

Если окружение уже существует, достаточно выполнить последние три команды. При использовании другого окружения запускайте их его интерпретатором. Не удаляйте `chromadb` из общего системного Python, если он нужен другим приложениям; создайте отдельное окружение для Live Hints.

После обновления проверьте, что файл `python\requirements.txt` содержит `aiohttp==3.14.3` и `requests==2.34.2`, а строк с `chromadb` в обязательных зависимостях нет.

## Файлы

- `Live.Hints.Setup.1.0.2.exe` — установщик;
- `LiveHints-Portable-1.0.2.exe` — portable-сборка;
- `SHA256SUMS.txt` — контрольные суммы.

## Требования

- Windows 10 или Windows 11;
- Python 3.11 или новее и зависимости из `python/requirements.txt`;
- совместимая NVIDIA GPU с CUDA для текущего STT-пути;
- Ollama и загруженная текстовая модель, по умолчанию `qwen3:8b`.

Portable-сборка не включает системный Python, CUDA, Ollama и модели. Она не является полностью автономной.

Перед запуском сверьте SHA-256 с опубликованным файлом контрольных сумм. Выпуски 1.0.0 и 1.0.1 больше не рекомендуются для нового окружения.

## Известные ограничения

- рабочий LLM-путь — только локальный Ollama;
- STT работает в режиме `cuda` и ориентирован на русский язык;
- постоянное хранилище ChromaDB отключено до появления исправленного выпуска;
- время ответа LLM зависит от модели и оборудования;
- пользовательские инструкции и облачные провайдеры остаются в планах.
