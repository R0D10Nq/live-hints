# История изменений (Changelog)

Все заметные изменения в проекте `live-hints` документируются в этом файле.

## [1.5.2] — 2026-09-09

### Комплексная доработка лендинга по результатам аудита The Fool
- **Устранение пустот и вертикального ритма (`site/styles.css`):** Оптимизированы межсекционные отступы (`--section-spacing: clamp(2.75rem, 5vw, 4rem)`), ликвидирован эффект «черных дыр» и провисания контента между блоками.
- **Интерактивный мокап видеозвонка в Hero (`site/index.html`):** Внедрен реалистичный интерфейс видеоконференции (Google Meet) с репликой интервьюера о сбоях в Kafka consumer group, парящим оверлеем подсказок Live Hints, индикатором REC и бейджем ультранизкой задержки TTFT 118 мс.
- **Ценностные метрики доверия (Trust Bar):** Добавлены ключевые показатели эффективности: 0 ₽ навсегда, задержка подсказки < 150 мс, 100% приватность без передачи звука в облако и поддержка 12+ платформ видеосвязи (Zoom, Meet, Teams, Яндекс Телемост).
- **Развернутая структура ответа STAR:** В карточке преимуществ наглядно визуализированы все 4 фазы ответа (Situation, Task, Action, Result) с акцентными бейджами и таймингами.
- **Визуализация защиты WDA:** Добавлено двухпанельное интерактивное сравнение экранов («Вы видите» с оверлеем подсказок против «Собеседник видит» с чистым экраном) на базе системного флага `WDA_EXCLUDEFROMCAPTURE`.
- **Практичные мокапы в секции «Как это работает»:** В Шаге 3 абстрактный шар заменен на мокап появления тезисной подсказки при вопросе о распределенных блокировках, в Шаге 4 внедрена интерактивная клавиатурная панель горячих клавиш (`Ctrl+Space`, `Alt+Scroll`, `Ctrl+Shift+Q`).
- **Windows HUD v1.5 в симуляторе оверлея:** Интерфейс симулятора переведен в аутентичный стиль Windows с зеленым индикатором статуса `STEALTH: ACTIVE`, строгими кнопками сворачивания/закрытия и возможностью мгновенного скрытия за 1 кадр с восстановлением по кнопке.
- **Построчный стриминг тезисов в симуляторе (`site/app.js`):** Реализована плавная посимвольная и построчная эмуляция стриминга подсказок с динамическим таймером задержки и визуальным подтверждением копирования в буфер обмена.
- **Сетка двух бесплатных тарифов (Dual Pricing):** Сформировано прозрачное позиционирование двух 0 ₽ планов («Гибридный старт» для любых ПК с 4–8 ГБ RAM и «Fully Local для RTX» для работы в закрытом контуре под жесткий NDA).
- **Закрытие возражений в FAQ:** Добавлены исчерпывающие ответы о поведении оверлея при переключении окон через Alt+Tab, видимости в Диспетчере задач, перехвате системного звука через WASAPI Loopback в наушниках и безопасности открытой лицензии MIT.
- **Усиленный финальный CTA:** Добавлена прямая кнопка скачивания Windows-инсталлятора `.exe`, ссылка на исходный код GitHub Releases и верификационный бейдж проверки безопасности VirusTotal Clean (0 детектов).
- **Доступность и статическое тестирование (`tests/unit/test_site_static.py`):** Внедрен медиа-запрос `prefers-reduced-motion` для снижения вестибулярной нагрузки, расширен набор статических тестов для контроля верстки, Windows HUD и отсутствия эмодзи.

## [1.3.0] — 2026-09-08

### Архитектура и LLM инференс
- **Гибридный LLM-провайдер (`HybridProvider`):** Реализован интеллектуальный маршрутизатор запросов (`python/llm/provider.py`), поддерживающий сверхбыстрые облачные API (Groq, Cerebras, Gemini Flash через OpenAI-совместимый протокол) с ультранизким TTFT (< 150 мс) и прозрачным автоматическим переключением (fallback) на локальную Ollama при ошибках сети, исчерпании квот или отсутствии API ключа.
- **Предотвращение VRAM-коллапса:** Использование облачного инференса высвобождает видеопамять (VRAM) для непрерывной локальной работы Whisper/STT без конкуренции за графический ускоритель.
- **Поддержка режимов работы:** Поддерживаются режимы `hybrid` (автовыбор с fallback), `local` (только Ollama) и `cloud` (только облако).
- **Опорный каркас подсказок (Anchor Bullet-Points):** Переработаны все системные промпты (`python/prompts.py`) и генератор контекстных инструкций (`python/classification.py`). Подсказки теперь формируются в телеграфном формате (3–5 пунктов по 5–8 слов), что устраняет «эффект диктора», позволяет кандидату охватить тезисы за 1 секунду и формулировать ответ своими словами.
- **Оптимизация задержки:** Ограничение `max_tokens` снижено до 100–160, что сократило время генерации подсказок более чем в 3 раза.
- **Тестирование:** Разработан модуль тестов `tests/unit/test_provider.py` (16 тестов), покрывающий одиночные вызовы, потоковую передачу SSE, симуляцию сбоев облака и прозрачное переключение на локальный стек.

## [1.1.0] — 2026-08-15

### Безопасность
- Устранил критическую уязвимость Path Traversal в IPC-обработчике `file:parse` (`main/ipc-handlers.js`), добавив строгую проверку принадлежности файла директории проекта и исключив чтение произвольных файлов системы.
- Ограничил политику CORS на LLM сервере (`python/llm_server.py`) до доверенных локальных источников `localhost` и `127.0.0.1`.
- Защитил Dashboard сервер (`python/dashboard_server.py`) токеном авторизации `DASHBOARD_TOKEN` и ограничил привязку хоста только к `127.0.0.1`.
- Добавил потокобезопасные блокировки `threading.Lock` в кэши (`python/cache.py`) и при обработке запросов к Ollama (`python/llm_server.py`) для исключения Race Condition и Data Race при конкурентных вызовах.
- Добавил whitelist разрешённых каналов в `preload.js` для метода `removeAllListeners`.

### Исправления ошибок
- Исправил опечатку в регистре переменной `StealthMode` на `stealthMode` в `main/stealth-manager.js`, из-за которой stealth-режим срабатывал на каждом цикле мониторинга.
- Отрефакторил переключение стелс-режима в `main.js`, убрав вызов несуществующего метода `setStealthModeState`.
- Устранил зависание WebSocket STT сервера (`python/stt_server.py`) при остановке, заменив бесконечный `asyncio.Future()` на `asyncio.Event()` с корректным graceful shutdown.
- Заменил устаревший вызов `asyncio.get_event_loop()` на `asyncio.get_running_loop()`.
- Устранил блокировку event loop FastAPI в эндпоинте `/hint`, вынеся синхронную генерацию в отдельный поток через `asyncio.to_thread`.
- Исправил запуск дочерних процессов в `main/process-manager.js`, заменив `process.cwd()` на вычисление путей относительно директории приложения.
- Исправил команду `taskkill` в `start-all.bat`, исключив принудительное завершение всех сторонних процессов Python.

### Производительность и утечки памяти
- Добавил возврат функций отписки (unsubscribe) для всех IPC-слушателей в `preload.js`.
- Оптимизировал фоновый мониторинг демонстрации экрана в `main/stealth-manager.js`: отключил генерацию миниатюр экранов (`thumbnailSize: { width: 0, height: 0 }`) и увеличил интервал опроса с 2 до 5 секунд для снижения нагрузки на CPU.

### Тестирование и CI/CD
- Исправил синтаксис и структуру пайплайна GitHub Actions (`.github/workflows/ci.yml`), добавив шаги валидации линтера, запуска Pytest и Jest на актуальной версии Node.js 20 и Python 3.11.
- Создал модульные тесты для ранее пустых файлов: `tests/unit/test_semantic_cache.py`, `tests/unit/test_transcriber.py`, `tests/unit/test_vector_db.py`.
- Добавил пакет `cross-env` в `devDependencies` `package.json`.
- Перевел конфигурацию линтера на современный стандарт ESLint 9 (`eslint.config.js`), удалил устаревший `.eslintrc.json`, настроил глобальные правила исключения для отчетов покрытия и артефактов IDE.
