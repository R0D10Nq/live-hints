# История изменений (Changelog)

Все заметные изменения в проекте `live-hints` документируются в этом файле.

## [1.2.1] — 2026-08-15

### Дизайн и векторные иконки
- Заменил все эмодзи в интерфейсе онбординга (карточки сценариев, зоны загрузки резюме и вакансий, индикаторы шагов, финальный экран) на качественные масштабируемые векторные SVG-иконки.
- Заменил эмодзи во всех компонентах основного интерфейса (микрофон, переключатель транскриптов, статистика истории сессий, карточки подсказок) на векторные SVG-иконки.
- Удалил эмодзи из системных промптов (`python/prompts.py`) и текстовых меток диалога.
- Зафиксировал строгое глобальное правило запрета смайликов и эмодзи в `GEMINI.md` и инвариантах `AGENTS.md`.

## [1.2.0] — 2026-08-15

### Переработка онбординга
- Полностью переработал логику онбординга: шаги определяются типами (mode, resume, context, vacancy, audio) вместо номеров, что исключает рассогласование навигации между режимами.
- Реализовал реальный сбор и сохранение данных пользователя: резюме, контекст, описание вакансии и выбранный микрофон теперь передаются в бэкенд Python через IPC-каналы `file:parse-buffer` и `file:save-context`.
- Добавил полноценный drag-and-drop для загрузки файлов с визуальной обратной связью.
- Добавил валидацию файлов: проверка размера (макс. 10 МБ) и формата (PDF, DOCX, TXT).
- Реализовал реальный тест микрофона через Web Audio API с визуализацией частотного спектра и автоостановкой через 10 секунд.
- Исправил описания карточек режимов: сравнение теперь идет по ключу конфигурации, а не по русскому имени.
- Убрал рандомную логику показа шага вакансии (`Math.random()`), шаг всегда показывается для режима «Собеседование».
- Заблокировал кнопку «Далее» до выбора сценария на первом шаге.
- Исправил клавиатурную навигацию: Enter теперь уважает состояние валидации.
- Исправил бейджи шагов — динамически отображают правильное количество шагов для выбранного режима.
- Исправил CSS-ошибку `align-items: container` на `center` в индикаторе шагов.
- Исправил синтаксическую ошибку HTML (пропущенный `=` в атрибуте class).
- Исправил опечатку `upgrade-icon` на `upload-icon` в зоне загрузки вакансии.
- Расширил `preload-onboarding.js` API-методами `parseFileBuffer` и `saveContextFile`.
- Добавил IPC-обработчик `file:parse-buffer` для безопасного парсинга загруженных файлов из буфера.
- Исправил использование `process.cwd()` в `file:save-context` на `path.resolve(__dirname)`.

## [1.1.0] — 2026-08-15

### Безопасность
- Устранил критическую уязвимость Path Traversal в IPC-обработчике `file:parse` (`main/ipc-handlers.js`), добавив строгую проверку принадлежности файла директории проекта и исключив чтение произвольных файлов системы.
- Ограничил политику CORS на LLM сервере (`python/llm_server.py`) до доверенных локальных источников `localhost` и `127.0.0.1`.
- Защитил Dashboard сервер (`python/dashboard_server.py`) токеном авторизации `DASHBOARD_TOKEN` и ограничил привязку хоста только к `127.0.0.1`.
- Добавил потокобезопасные блокировки `threading.Lock` в кэши (`python/cache.py`) и при обработке запросов к Ollama (`python/llm_server.py`) для исключения Race Condition и Data Race при конкурентных вызовах.
- Добавил whitelist разрешённых каналов в `preload.js` для метода `removeAllListeners`.

### Исправления ошибок
- Исправил опечатку в регистре переменной `StealthMode` на `stealthMode` в `main/stealth-manager.js`, из-за которой stealth-режим срабатывал на каждом цикле мониторинга.
- Отрефакторил переключение стелс-режима в `main.js`, убрав вызов несуществующего метода `setStealthModeState`.
- Устранил зависание WebSocket STT сервера (`python/stt_server.py`) при остановке, заменив бесконечный `asyncio.Future()` на `asyncio.Event()` с корректным graceful shutdown.
- Заменил устаревший вызов `asyncio.get_event_loop()` на `asyncio.get_running_loop()`.
- Устранил блокировку event loop FastAPI в эндпоинте `/hint`, вынеся синхронную генерацию в отдельный поток через `asyncio.to_thread`.
- Исправил запуск дочерних процессов в `main/process-manager.js`, заменив `process.cwd()` на вычисление путей относительно директории приложения.
- Исправил команду `taskkill` в `start-all.bat`, исключив принудительное завершение всех сторонних процессов Python.

### Производительность и утечки памяти
- Добавил возврат функций отписки (unsubscribe) для всех IPC-слушателей в `preload.js`.
- Оптимизировал фоновый мониторинг демонстрации экрана в `main/stealth-manager.js`: отключил генерацию миниатюр экранов (`thumbnailSize: { width: 0, height: 0 }`) и увеличил интервал опроса с 2 до 5 секунд для снижения нагрузки на CPU.

### Тестирование и CI/CD
- Исправил синтаксис и структуру пайплайна GitHub Actions (`.github/workflows/ci.yml`), добавив шаги валидации линтера, запуска Pytest и Jest на актуальной версии Node.js 20 и Python 3.11.
- Создал модульные тесты для ранее пустых файлов: `tests/unit/test_semantic_cache.py`, `tests/unit/test_transcriber.py`, `tests/unit/test_vector_db.py`.
- Добавил пакет `cross-env` в `devDependencies` `package.json`.
- Перевел конфигурацию линтера на современный стандарт ESLint 9 (`eslint.config.js`), удалил устаревший `.eslintrc.json`, настроил глобальные правила исключения для отчетов покрытия и артефактов IDE.
- Ужесточил git-хуки в `.githooks/` для контроля формата сообщений коммитов на русском языке без префиксов и корректного логирования ошибок тестов.
- Удалил `AGENTS.md` из списка игнорируемых файлов `.gitignore`.
