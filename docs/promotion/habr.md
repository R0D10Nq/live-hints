# Черновик технической публикации

## Заголовок

Как устроен локальный Windows-overlay для транскрипции созвона и подсказок через Ollama

## Короткое описание

Live Hints захватывает системный звук через WASAPI loopback, передаёт фрагменты в локальный `faster-whisper`, а затем строит потоковую подсказку через Ollama. Electron отвечает за окно поверх приложений, Python — за STT и LLM-сервисы.

В статье стоит показать:

- почему выбран локальный контур и какие данные всё же скачиваются при установке;
- как устроено разделение Electron, WebSocket STT и HTTP LLM;
- где находится реальная задержка и почему 500 мс нельзя обещать;
- как проверяются IPC, пути файлов и локальные порты;
- какие ограничения остаются: NVIDIA GPU, русский режим STT, Ollama и отсутствие готовых облачных адаптеров.

Исходный код и выпуск: https://github.com/R0D10Nq/live-hints
