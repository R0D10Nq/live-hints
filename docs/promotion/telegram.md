# Публикация для Telegram

## Основной вариант

**Live Hints — локальная транскрипция созвона и подсказки через Ollama**

Открыл исходники Windows-приложения, которое захватывает системный звук через WASAPI, распознаёт русскую речь локальным `faster-whisper` и показывает потоковые подсказки в окне поверх созвона.

Что уже работает:

- системный звук и дополнительный канал микрофона;
- локальная транскрипция на совместимой NVIDIA GPU;
- ответы через Ollama без отправки аудио в облачный LLM;
- история сессий, компактный режим и анализ скриншота через LLaVA;
- установщик, portable-сборка и SHA-256;
- 621 локальная проверка, CI и CodeQL.

Ограничения тоже важны: нужны Windows 10/11, Python, совместимая NVIDIA GPU и Ollama. Portable-файл пока не включает Python, CUDA, Ollama и модели. Первый токен локальной модели в текущих замерах появляется примерно за 2–3 секунды, а не за обещанные «мгновенные» 500 мс.

## Короткий вариант

Открыл Live Hints — Windows-overlay для локальной транскрипции русского созвона через `faster-whisper` и потоковых подсказок через Ollama.

Есть установщик, portable-сборка, скриншоты, CI и открытые задачи для первых вкладов. Нужны Windows, Python, совместимая NVIDIA GPU и Ollama; полностью автономной сборки пока нет.
