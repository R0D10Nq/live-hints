# Черновик публикации для Telegram

**Live Hints — локальные подсказки поверх созвона**

Собрал Windows-приложение, которое слушает системный звук созвона, переводит русскую речь в текст и показывает краткие подсказки рядом с рабочим окном.

Что внутри:

- захват системного звука через WASAPI;
- локальный `faster-whisper` на NVIDIA GPU;
- потоковые ответы через Ollama без отправки аудио в облако;
- история сессий, режим поверх окон и анализ скриншота через LLaVA.

Проект открыт, есть установщик и portable-сборка. Нужны Windows 10/11, NVIDIA GPU, Python и Ollama. Облачные провайдеры пока не заявляю: рабочий путь сейчас только локальный Ollama.

Ссылка: https://github.com/R0D10Nq/live-hints

Буду благодарен за проверку на другой видеокарте, отчёты о задержке и звезду, если сценарий оказался полезным.
