# План публичного запуска

Цель — привлечь первых пользователей и получить содержательную обратную связь без накрутки звёзд, массовых рассылок и публикации персональных данных.

## Перед публикацией

- проверить последний выпуск и контрольные суммы;
- открыть README в режиме инкогнито и пройти путь «Скачать → Запустить»;
- убедиться, что в скриншотах нет имён, вакансий, токенов и записей разговоров;
- добавить ссылку на задачу или обсуждение, где можно задать вопрос;
- подготовить короткий ответ о требованиях: Windows, NVIDIA GPU, Python и Ollama.

## Каналы

1. GitHub Release — основной источник установки и изменений.
2. GitHub Discussions — вопросы, сценарии использования и обратная связь.
3. Личный Telegram или тематическое сообщество — только одна публикация с явной пользой и ссылкой на исходный проект.
4. Habr или другой технический блог — подробный разбор локальной архитектуры, задержек и ограничений.

Не дублируйте один и тот же текст в десятках каналов. Отвечайте на вопросы по существу и фиксируйте повторяющиеся проблемы в задачах.

## Метрики на первые 14 дней

- уникальные посетители страницы;
- переходы в Releases;
- скачивания установщика и portable-файла;
- число запусков CI после пользовательских установок;
- содержательные задачи и запросы на изменение;
- звёзды как итог полезности, а не как единственная цель.

## После публикации

- раз в два дня отвечать на новые вопросы;
- раз в неделю выпускать небольшое исправление или отчёт о совместимости;
- отмечать в README проверенные GPU, версии Windows и модели Ollama;
- закрывать дубли задач ссылкой на единый источник решения.
