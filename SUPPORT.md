# Помощь

Перед вопросом проверьте разделы [README.md](README.md) и историю [задач](https://github.com/R0D10Nq/live-hints/issues).

Для ошибки используйте [форму отчёта](https://github.com/R0D10Nq/live-hints/issues/new?template=bug_report.yml). Для идеи — [форму новой возможности](https://github.com/R0D10Nq/live-hints/issues/new?template=feature_request.yml).

В вопросе укажите Windows, версию выпуска, модель Ollama, GPU и команду запуска. Не публикуйте ключи, записи разговоров и содержимое резюме.
