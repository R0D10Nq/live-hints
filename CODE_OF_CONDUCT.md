# Правила сообщества

Участники проекта общаются уважительно, по существу и без дискриминации.

Недопустимы:

- оскорбления, угрозы и преследование;
- дискриминационные высказывания по любому личному признаку;
- публикация чужих персональных данных и секретов;
- намеренный спам, искусственная накрутка активности и вредоносные изменения;
- обсуждение уязвимостей в публичной задаче до исправления.

Поддерживайте техническую критику фактами, шагами воспроизведения и уважительным тоном. Нарушения можно передать сопровождающему проекта через приватный канал из [SECURITY.md](SECURITY.md) или через настройки жалобы GitHub.
