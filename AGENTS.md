# AGENTS.md — live-hints

## Назначение файла

Этот файл определяет роли, ответственности и протоколы взаимодействия
AI-агентов для разработки проекта live-hints. Используется в среде Windsurf
для координации автономных агентов.

## Быстрый старт для нового агента

1. Определи свою роль: AudioPipelineAgent | TranscriptionAgent | LLMAgent | UIAgent | DevOpsAgent
2. Изучи входные/выходные интерфейсы в разделе 7.2
3. Проверь глобальный контекст в 7.3.1 — целевая latency 500ms критична
4. Используй команды из 7.5 для типовых задач

## Критические инварианты (не нарушать без эскалации)

- End-to-end latency не должна превышать 500ms в 95% случаев
- Аудиоданные не покидают устройства в fully_local режиме
- Все ошибки компонентов логируются с trace_id для корреляции

## Контакты и эскалация

- Технические вопросы: создать issue с label `agent-question`
- Критические сбои: немедленный `/escalate` с приложенными логами
